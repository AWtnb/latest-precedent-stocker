# README

## 概要

[裁判所ウェブサイト](https://www.courts.go.jp/hanrei/search1/index.html) から最新の判例を定期取得し、スプレッドシートにストックするGASプロジェクト。

Googleフォームからメールアドレスと日付範囲を入力すると、該当期間の判例データをCSV・テキスト形式で添付メール送信する。

---

## 開発環境

使用ツール：[clasp](https://github.com/google/clasp)

1. `npm install`
1. Googleドライブ上にフォームを作成し、右上のメニューからスクリプトを作成。URLからスクリプトIDを取得する
1. `.clasp.json` を以下の内容で作成して `（スクリプトID）` を書き換える

    ```json
    {
      "scriptId": "（スクリプトID）",
    }
    ```

1. `clasp push` でローカルの変更をGASエディタに反映
1. `clasp open-script` でGASエディタを開く
1. スクリプトプロパティに `SHEET_ID` のキーでシートIDを登録しておく
1. トリガーを設定する
    - `main` : 時間ベース（毎日、夜などの適当な時間に）
    - `onFormSubmit` : フォームから - フォーム送信時

## ファイル構成

| ファイル | 役割 |
|---|---|
| `common.js` | 定数・共通ユーティリティ（列定義・日付変換など） |
| `main.js` | 判例の定期取得・スプレッドシートへのストック |
| `response.js` | フォーム送信時のメール送信処理 |

## スプレッドシートの列構成

| 列 | 内容 |
|---|---|
| A | 判例URL |
| B | 判決日（ISO形式: `YYYY-MM-DD`） |
| C | 判決日（和暦） |
| D | 裁判所名 |
| E | 支部名 |
| F | 裁判の種類 |
| G | 事件番号 |
| H | 事件名 |
| I | 判示事項要旨 |

---

## フォームの設問構成

`onFormSubmit` は回答順に依存しているため、以下の順番で設問を作成すること。

| 順番 | 設問 | 形式 |
|---|---|---|
| 1 | 開始日 | 日付（`YYYY-MM-DD` 形式の文字列データが送信される） |
| 2 | 終了日 | 日付（`YYYY-MM-DD` 形式の文字列データが送信される） |
| 3 | メールアドレス | テキスト |

---

## 動作仕様

### 定期取得（`main`）

- 実行日の **前日〜30日前** の期間を対象に裁判所サイトを検索する
- スプレッドシートにすでに存在するURLはスキップする（重複防止）
- 1件ごとに1秒のウェイトを挟む

### メール送信（`onFormSubmit`）

- **知的財産高等裁判所** の判例は除外される
- 結果は **審級順（最高裁 → 高裁 → その他）**、同審級内は **判決日の降順** でソートされる
- 該当件数が0件の場合は、その旨を本文のみで送信する
- 該当件数が1件以上の場合、以下の2ファイルを添付して送信する
    - `hanrei_（開始日）_（終了日）.csv`：B列（ISO日付）を除いた全列
    - `hanrei_（開始日）_（終了日）.txt`：日付・裁判所・事件番号・URL・要旨を整形したテキスト
